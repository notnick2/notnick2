### 🚀 About Me

I turn ambitious product ideas into systems that don't fall over when real users show up.

- 🏗️ **Founding Engineer @ Magicslides** — built an AI presentations platform from **zero**, scaled it to **600K+ registered users**, **50K+ monthly active users**, **800K+ presentations generated**, and **$350K+ ARR**.
- ⚡ Architected backends that absorb **millions of requests** and **tens of millions of LLM tokens** in production.
- 🤖 Shipped AI **before the GPT era** — and pioneered chatbots that don't just reply with text, they build **complete, professional presentations end-to-end**.
- 🧠 Built lead-data pipelines + automated email generation across **100K+ leads** — compressing a **month of manual work into ~2 days**.
- 🌍 Worked across software teams in the **US, Europe, and Latin America** — at **SlideModel**, shipped AI features serving **350K+ businesses**.
- 🧩 I take **complete ownership** — database schema → API → deployed UI. Clean, modular, typed.
